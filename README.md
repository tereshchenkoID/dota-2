# Spin Arcade / Dota Spins

Браузерная аркада со страницей выбора игры и отдельным слотом Dota Spins. Без денежных ставок, платежей, авторизации и обязательных переменных окружения. Next.js обрабатывает маршруты на сервере; игровой прогресс хранится в браузере.

## Запуск

Node.js **22.12+**, рекомендуется 24 LTS. Пакетный менеджер — npm.

```bash
npm install
npm run dev
```

- `http://localhost:3000/en/` — главная и выбор слота.
- `http://localhost:3000/en/dota/` — игра Dota Spins.

```bash
npm run lint
npm run build
npm run preview
```

Сборка — `.next/`. Production: `npm run start` (порт 3000), проверочный запуск: `npm run preview` (порт 4173). Proxy требует Next.js runtime; `output: export` не используется.

Автотесты, Vitest и команда `test` удалены по принятой структуре проекта. Проверки — ESLint, Stylelint, production build и ручная проверка пользовательских сценариев в браузере.

## Стек и соглашения

Next.js App Router, React, **JavaScript с JSX в файлах `.js`**, Sass / SCSS Modules, next-intl, Zustand и Zustand Persist. JSX компилируется штатным SWC Next.js, SCSS — Sass; отдельная Babel-конфигурация не нужна. TypeScript, Tailwind и игровые движки не используются.

У каждого визуального компонента своя папка: `index.js` и `index.module.scss`. Имена компонентных папок — PascalCase, классы — одно слово или camelCase; в JS только `styles.name`. `layout.scss` содержит шрифты, reset, переменные и базовые правила документа. В SCSS-модулях используется локальная вложенность.

```text

  components/

  widgets/

    Footer/index.js + _view/
    Modals/
      index.js                         # единственный хост и оболочка Modal
      registry.js                      # lazy-компоненты, заголовки и варианты
      ProfileModal/ AvatarModal/ SettingsModal/
      StatsModal/ GuideModal/ ConfirmModal/ ResultModal/
  modules/Dota/
    components/                        # DotaGame, GameViewport, SlotMachine и др.
    config/ engine/ store/game.js
  store/modal.js + profile.js
  proxy.js                             # серверная маршрутизация языка
  hooks/                               # useTranslation, useChangeLanguage, useStoreHydration
```

Визуальные компоненты имеют `index.js` и соседний `index.module.scss`, когда нужны собственные стили. Компонентные директории — PascalCase; хуки — camelCase; служебные группы и маршруты — lowercase. Расширение React-файлов — `.js`. Единственный алиас `@/*` указывает на `src/*`.

```js
import Button from '@/components/Button'
import DotaGame from '@/modules/Dota/components/DotaGame'
import { useModalStore } from '@/store/modal'
```

## Модалки и стили

`widgets/Modals/registry.js` связывает имя окна с lazy-контентом и ключом перевода. Только хост рендерит общую `components/Modal`; контентные компоненты не создают собственную оболочку. `openModal(name, props, options)` добавляет окно в стек, `closeModal()` закрывает верхнее, `closeAllModals()` закрывает все. Повторное открытие того же окна не создаёт копию. AvatarModal открывается поверх профиля; выбор героя закрывает только пикер и возвращает в профиль. Отмена подтверждения возвращает в настройки. Фокус, Escape и блокировка прокрутки обрабатываются общей оболочкой.

При переходе между страницами стек очищается. В игровом fullscreen портал размещается внутри игрового контейнера. Zustand хранит только состояние открытых окон в памяти; профиль и игровой прогресс сохраняются отдельно.

`scss/_config.scss` подключается через `sassOptions.additionalData`: повторять импорты в каждом модуле не нужно. Вместо отдельной папки `styles` используются `@include tab-s`, `@include desk-s`, `@include flex(...)`, `@include size(...)`, `rem(...)`. Брейкпоинты: 360 / 560 / 768 / 992 / 1024 / 1280 / 1440 px.

Цвета, поверхности, границы, веса шрифтов и радиусы сайта определены CSS custom properties в `app/[locale]/layout.scss`: `--color-bg`, `--color-surface`, `--color-link`, `--color-border`, `--font-weight-*`. Игровая тема Dota ограничена GameViewport. Общая модалка сбрасывает игровые акценты на цвета сайта. Изображения используют `next/image` с явными размерами и `images.unoptimized: true`: сервер оптимизации изображений не нужен.

## Переиспользуемый UI и модалки

- `Button`: варианты `primary`, `secondary`, `ghost`, `danger`, `icon`. Игровые элементы с отдельным оформлением используют нативный `button`.
- `Text`: `as`, числовые размеры `1/2/3` (19/16/14 px), `color="text|muted|accent"`. Пример: `<Text size={3} color="muted">...</Text>`.
- `Heading`: `as` и числовые размеры `1/2/3` (от большого к маленькому).
- `Link`: внутренние переходы через next-intl Link, внешние — через обычный `<a>`.
- `Modal`: общий нейтральный стиль сайта, нативный dialog, фокус, Escape и анимация появления.

Открытие окон централизовано через Zustand:

```js
useModalStore.getState().openModal("settings");
useModalStore.getState().openModal("guide");
useModalStore.getState().openModal("stats");
useModalStore.getState().openModal("restart");
useModalStore.getState().closeModal();
```

`widgets/Modals` отображает стек окон. Победа и поражение тоже открываются через store/modal; результат не появляется повторно при обычных перерендерах. При смене страницы окно закрывается. В игровом fullscreen хост порталом переносит окно внутрь игрового контейнера, сохраняя **стиль сайта**; фоновые элементы блокируются через `inert`. Состояние открытой модалки не сохраняется в localStorage.

## Темы и страницы

Оболочка SPIN ARCADE имеет нейтральную палитру. Тема Dota, Reaver / Radiance, игровые панели и эффекты ограничены `modules/Dota/components/GameViewport/`. Общие модалки задают собственную типографику и цвета, поэтому тема слота их не меняет.

Главная показывает доступный слот с настоящим переходом на `/<locale>/dota/`. Для новой игры добавьте отдельный модуль, `app/[locale]/(game)/<game>/page.js`, клиентский `_view`, маршрут в `(game)` и карточку каталога. Движок Dota и разметка главной не смешиваются. Футер занимает всю ширину окна, а его внутренний контейнер ограничен той же шириной, что и сайт.

## Игровой цикл

Игрок начинает со 100 HP и 22 вращениями; Roshan имеет 1000 HP. Поле 5×3, пять линий: три горизонтали и две V-образные диагонали `[0,1,2,1,0]` / `[2,1,0,1,2]`. Совпадения из 3/4/5 символов с первого барабана активируют эффект с множителями 1/2/4. Несколько линий складываются.

Барабаны используют непрерывно движущуюся вертикальную ленту символов. Останавливаются по очереди, с короткой анимацией фиксации на сохранённом результате. `prefers-reduced-motion` отключает движение. Итог хода не зависит от кадров анимации.

Roshan атакует каждый третий ход: 5 урона при HP > 660, 10 при HP 301–660, 15 при HP ≤ 300. Фаза определяется после удара игрока. Убитый босс не отвечает. Нулевые HP босса — победа; нулевые HP игрока или отсутствие вращений — поражение. При последнем ударе победа имеет приоритет.

### Предметы

| Предмет           | 3 / 4 / 5 совпадений                                                     |
| ----------------- | ------------------------------------------------------------------------ |
| Healing Salve     | +20 / 40 / 60 HP до атаки Roshan, максимум 100 HP                        |
| Divine Rapier     | +80 / 160 / 240 урона                                                    |
| Daedalus          | урон ×1.5 / 2 / 2.5                                                      |
| Butterfly         | +1 / 2 / 3 вращения                                                      |
| Black King Bar    | блок следующих 1 / 2 / 3 атак                                            |
| Aghanim’s Scepter | +35 / 70 / 105% урона                                                    |
| Refresher Orb     | повтор предыдущего эффекта 1 / 2 / 3 раза: урон, лечение, щиты, вращения |

Refresher помнит последний эффект между пустыми ходами. Награды: победа — 180 XP и 250 золота; поражение — награда за участие и нанесённый урон. Каждые 250 XP повышают уровень. Золото используется только как показатель прогресса.

### Баланс

Все параметры находятся в `modules/Dota/config/`. RNG — `crypto.getRandomValues`; функции генерации принимают подменяемый генератор. Вес героя — 12, предмета — 3. Чтобы комбинации оставались достижимыми при 13 символах, ход выбирает взвешенный «символ сбора»: каждая ячейка с вероятностью `rallyChance` (44%) получает его, иначе выбирает из полного пула. Гарантированного выигрыша нет. `rallyChance: 0` даёт независимые выборы.

Добавление героя: объект в `config/heroes.js`, локальное изображение, ключи названия и способностей во всех словарях. Добавление предмета: конфигурация в `config/items.js`, чистая функция в `engine/damage.js`, изображение и переводы. Урон героев → Rapier → остальные предметы в порядке `itemEffects` → округление.

## Локализация

Язык — первый сегмент URL: `/en/`, `/ru/`, `/uk/`; игра — `/<locale>/dota/`. `src/proxy.js` использует next-intl routing с обязательным префиксом: `/` → `/en/`, `/dota/` → `/en/dota/`. Неизвестный языковой префикс, например `/fr/dota/`, заменяется на `/en/dota/`. Query-параметры сохраняются. API, `_next`, ассеты и пути файлов исключены из matcher.

`i18n/routing.js` задаёт `en/ru/uk`, default `en`, `localePrefix: always`, `localeDetection: false`, `localeCookie: false` — как в примере betman, без авторизации. `request.js` загружает локальные JSON-словари, `navigation.js` экспортирует locale-aware Link и navigation API. Словари вложенные, вызовы `t('game.hp')` сохраняются. Layout валидирует locale и передаёт серверные messages в штатный `NextIntlClientProvider`. Самописного `I18nProvider` и HTML/meta-редиректов нет.

`useTranslation` — адаптер над `useLocale`, `useTranslations` и `useFormatter` для существующих компонентов. `useChangeLanguage` меняет префикс с полной перезагрузкой, сохраняя query/hash. Восстановление Zustand выполняет отдельный `StoreHydration`, оно не связано с i18n. Группы `(entry)` и `(redirect)` удалены.

## Сохранения

Zustand Persist хранит уровень, XP, золото, победы, поражения, лучший результат, суммарные вращения, настройки и текущий бой в `dota-spins-v1`. Пути модулей изменены без изменения ключа сохранения: прежний прогресс сохраняется.

Результат вращения записывается до анимации. При перезагрузке сохранённый pending-ход завершается один раз. Флаг `rewarded` исключает повторную награду. Если перейти на главную во время вращения, незавершённая анимация продолжится при возвращении к игре; перезагрузка страницы также корректно завершит этот ход.

Настройки → Сбросить прогресс → Подтвердить очищает игру, сохраняя звук; язык определяется URL. Для полного сброса удалите `dota-spins-v1` в браузере. При недоступном localStorage игра работает в памяти.

## Ассеты, звук и fullscreen

PNG героев и семи предметов, официальный арт Roshan из Diretide 2020 и фон хранятся локально. Источники — `public/assets/asset-sources.json`. Исходные SVG остаются неиспользуемыми заготовками. Заменять изображения можно через пути в конфигурациях и `modules/Dota/components/RoshanBoss/index.js`.

Переключатель звука включает оригинальные WAV-звуки Dota 2: удары Juggernaut, реакции Roshan, Slam и Healing Salve. Маршрутизация — `config/audio.js`, воспроизведение — `lib/sound.js`. Web Audio разблокируется пользовательским кликом; выключение отменяет активные и ожидающие загрузки боевые клипы. Ошибка аудио не мешает игре.

Кнопка разворачивания разворачивает только игровое окно; Escape или повторное нажатие возвращает страницу. При недоступности Fullscreen API используется разворачивание во вкладке. Окна и управление доступны внутри этого режима.

Материалы Dota 2 принадлежат Valve. Проект не связан с Valve; для коммерческого запуска требуется отдельная проверка прав.

## Деплой

Используйте Next.js preset на Vercel либо Node.js-сервер: `npm ci`, `npm run build`, `npm run start`. Сборка хранится в `.next`, запуск обслуживает страницы и proxy. На собственном сервере Nginx может проксировать запросы на `http://127.0.0.1:3000`.

Статический хостинг папки `out/` больше не используется: серверные редиректы и proxy выполняются Next.js runtime.

## Ограничения и будущий backend

Локальная одиночная игра без аккаунтов, синхронизации, соревнований и сетевого рейтинга. Первая загрузка страницы требует HTTP(S); service worker не добавлен. Сохранения доступны для изменения пользователем и не являются доверенным результатом.

Движок остаётся чистым JavaScript без React и хранилища. UI, игровой Zustand store, store/modal, конфигурации и адаптер сохранений разделены. Для рейтингов и PvP генерация, проверка ходов и награды должны переехать на сервер; фиктивных API и action-файлов сейчас нет.

## Иконки, линтеры и профиль

Именованные импорты иконок — `lucide-react`. `npm run lint` проверяет JS и SCSS, `npm run lint:fix` исправляет форматирование и порядок. Тестовые файлы не добавлены.

Имя и аватар сохраняются в `spin-arcade-profile-v1`; боевой прогресс — в `dota-spins-v1`. Каталог аватаров: `src/modules/Dota/config/avatars.json`, 127 героев с поиском и локальными портретами. Выбор языка доступен в шапке и SettingsModal, звук — в SettingsModal и игре. Ниже 768 px навигация скрывается из шапки; ниже 560 px остаются логотип, уровень и кнопка меню. Футер ниже 768 px располагается в одну колонку. В футере — «Наверх».

## Шрифты, размеры и каталог

Шрифты подключены через `next/font/google` в `app/[locale]/layout.js`: Inter для сайта, Roboto Condensed и Cinzel для Dota. Next скачивает шрифты при сборке и раздаёт их с сайта. Веса заданы custom properties `--font-weight-*`.

Параметры темы находятся непосредственно в `app/[locale]/layout.scss`. CSS-длины задаются через Sass `rem(...)`; для custom properties используется интерполяция `#{rem(...)}`. Отступы кратны 2 px, отступы и размеры текста указываются непосредственно в SCSS компонентов. Базовые 16 px внутри функции `rem()` служат коэффициентом перевода.

Обращения к CSS Modules только через точку: `styles.menu`, `styles.account`. Варианты компонентов используют явные карты классов. Правило закреплено в ESLint.

На главной добавлены League of Legends, Counter-Strike 2, Valorant и World of Warcraft. Компонент `Upcoming` показывает статус «Скоро / В разработке» и не содержит ссылки или обработчика перехода. Данные карточек — `constant/games.js`.

«Как играть» выбирается централизованно по текущему pathname без языкового префикса в `widgets/Modals/GuideModal/registry.js`: `/dota` и `/dota/` открывают правила Dota Spins, главная — общую справку Spin Arcade. Все кнопки, включая меню аккаунта и панель игры, используют тот же resolver. Для новой игры добавьте её маршрут, заголовок и компонент инструкции в `gameGuides`.

Адаптив строится от мобильных базовых стилей с расширениями через именованные миксины `mob-s`, `mob-m`, `tab-s`, `tab-m`, `tab-l`, `desk-s`, `desk-m` (min-width).

## Соглашения компонентов

Компоненты объявляются стрелочными функциями с отдельным `export default`. Классы составляются через `clsx`; карты вариантов, размеров и тонов находятся вне JSX. Именованные CSS-классы используются через точку. ESLint проверяет объявления компонентов и запрещает шаблонные строки внутри `className`.

Иконки: `<Icon name="chevron-down" />` из `@/components/Icon`; названия совпадают с Lucide. Прямые импорты библиотеки централизованы в Icon. Пользовательские хуки находятся в `src/hooks`. Названия героев и предметов остаются английскими во всех локалях.

Игра открывается после восстановления Zustand, декодирования всех символов, фона, арта Roshan и игровых шрифтов. Ошибка ресурсов показывает повторную загрузку. Совпадения отмечаются линиями через центры символов. Комбинации, способность, урон и лечение выводятся на полупрозрачной плашке по центру поля и не меняют высоту игрового блока. Перезапуск оформлен отдельной кнопкой с подтверждением. На барабанах остаются только изображения. Названия способностей английские во всех локалях. Хедер и футер используют общий `Logo`.

Баланс: базовый урон героев 48 / 60 / 42 / 53 / 57 / 45, 22 вращения, rallyChance 44%. Контрольная симуляция 15 000 забегов с фиксированным генератором дала 72,06% побед (до изменения — 18,3%); это оценка сложности, а не гарантия результата.

Для пар `width`/`height` используется `@include size(width, height)`, для квадратов — `@include size(value)`. Все цветовые custom properties имеют префикс `--color-`, включая игровые акценты.
