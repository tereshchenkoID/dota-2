# Влияние билдов и достижимость максимума

Seed 20261016. Конфигурация не менялась во время измерений. Исходные числа и параметры: [build-evidence.json](build-evidence.json).

## Методика

- Полные забеги: 6 стратегий × 10000 = 60 000.
- Приоритетная прокачка каждого из 10 улучшений: ещё 100 000 забегов. Целевое улучшение берётся, когда предложено; иначе используется adaptive.
- Исключение каждой из 17 наград: 170 000 забегов плюс 10 000 контрольных adaptive.
- Стенд отдельных боёв: 3 этапа × 5 билдов × 10 000 = 150 000 боёв.
- RNG боя/модификаторов согласован по seed и этапу; решения не видят будущих выпадений.
- Во всех полных забегах число принудительно остановленных на лимите симулятора — 0.

## Контролируемый бой на этапе 30

У каждого билда одинаковый бюджет 29 уровней, распределённый по его направлению. Baseline намеренно без улучшений. Все начинают с полного HP своего билда, без руны, с одинаковыми seed боя и модификатора. Доступность точного набора наград и потери HP на предыдущих этапах здесь не моделируются. Battle Recovery почти не проявляется на таком стенде, поскольку работает между боями. Этот эксперимент измеряет силу готового билда, а не шанс получить его или дойти до этапа 30.

## Какие награды влияют на результат

Удаление меняет заменяющие предложения и будущие решения, поэтому отрицательная разница не означает, что предмет наносит вред численно. ## Что означает максимум

- У этапов игры нет конечного максимума. Этап 30 — ориентир сложности, а не последний босс.
- У одного улучшения максимум 30. Понадобится не меньше 30 побед и выборов именно этого улучшения; руны отодвигают цель.
- Все десять улучшений по 30 — 300 постоянных выборов: минимум 300 побед, после чего можно войти на этап 301. Это теоретический минимум, не обещание достижимости.
- В обычном adaptive средний самый высокий уровень одного улучшения — 3.12, максимальный увиденный — 13.

## Что видит игрок

Current Build показывает наивысший уровень и сумму уровней отдельно от этапа; одинаковые комбинации 3/4/5 героев без билда, с билдом и с активной руной; примеры усиления Rapier, Salve, Butterfly и BKB, максимум HP и стартовые вращения. Примеры вычисляет настоящий resolver для текущего Roshan, без ограничения оставшимися HP и без обещания будущих выпадений.

В бою выделены метки «Билд +…» и «Руна +…». Нанесённый урон копится по источникам за забег. При избыточном уроне компоненты распределяются пропорционально и округляются до фактически снятых HP, чтобы добивание не обнуляло видимый вклад билда. Это атрибуция урона, а не причинная оценка альтернативного забега без улучшений. Старый урон до появления счётчика не приписывается выдуманным источникам.

## Повторный запуск

```bash
npm run simulate:arcade -- 10000 20261016 build-strategies
npm run simulate:impact -- 10000 20261016 build-reward-impact
npm run simulate:builds -- 10000 20261016
npm run simulate:progression -- 10000 20261016
npm run report:builds
```

Сырые отчёты создаются в игнорируемой папке reports. Этот отчёт и компактный JSON сохраняют проверенные результаты в документации. При изменении баланса измерения нужно повторить; сравнивать старые числа с новой конфигурацией как один эксперимент нельзя.
