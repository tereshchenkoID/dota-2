# UI Kit Spin Arcade

Живая витрина: `/<locale>/ui-kit/` (`en`, `ru`, `uk`). Ссылка доступна в футере. Это лёгкая страница на реальных компонентах приложения, без отдельного Storybook runtime и новых зависимостей.

## Границы системы

Оболочка сайта, страницы каталога, профиль, формы и все модалки используют одну дизайн-систему. Игровой мир Dota остаётся отдельной темой внутри GameViewport; его изображения, линии, эффекты попадания и крупная игровая SPIN-кнопка не задают оформление сайта. Игровые toolbar-кнопки и кнопки билда используют общий Button.

Общие элементы управления имеют **44 px** высоты: Button, квадратная кнопка, Input с рамкой, Select и Toggle. Размер не меняется между брейкпоинтами. У карточек выбора героя/награды высота зависит от контента: это интерактивный Panel, а не растянутая обычная кнопка. Основная кнопка вращения игры — отдельный компонент SpinButton с собственной игровой иерархией (44 px на телефоне, 60 px на большем экране).

Не переопределяйте высоту, padding, цвет и шрифт Button/Input/Select в компоненте-потребителе. `className` предназначен для положения в layout: ширины, grid-column, align-self и подобных свойств. Новое визуальное состояние добавляется в базовый компонент как именованный вариант, а не как локальное исправление поверх него.

## Компоненты

| Компонент | Основной API | Назначение |
|---|---|---|
| Button | `color="primary|secondary|ghost|danger"`, `square`, `full`, `selected`, `as` | Действия, ссылки-кнопки, иконки |
| Link | `href`, стандартные атрибуты ссылки | Locale-aware навигация; внешние URL — обычный anchor |
| Input | `label`, `icon`, `description`, `error`, стандартные input props | Поля с единым focus/error/disabled оформлением |
| Select | `value`, `options`, `onChange(nextValue)`, `label`, `disabled` | Кастомный listbox с управлением клавиатурой |
| Toggle | `checked`, `onChange(nextBoolean)`, `label`, `onLabel`, `offLabel` | Булевый переключатель |
| Panel | `variant="default|raised|inset"`, `padding={0|1|2}`, `interactive`, `selected`, `as` | Поверхности и карточки; padding 0 / 12 / 20 px |
| MetricGrid | `items=[{id,label,value,icon}]`, `columns={2|3}` | Карточки статистики с едиными dt/dd и типографикой |
| SettingRow | `label`, `description`, `icon`, `children` | Строка настройки с адаптивным расположением контрола |
| ActionItem | `icon`, `href` или `onClick` | Кнопка/ссылка-строка в профиле, стандартная высота 44 px |
| Badge | `color="neutral|accent|success|danger|image"` | Компактная неинтерактивная метка |
| Progress | `value`, `max`, `label` | Нативный доступный progress с единым оформлением |
| Container | `as`, `className` | Общая ширина страницы и горизонтальные отступы |
| Text | `as`, `size={1..5}`, `color`, `weight` | Основной текст и подписи |
| Heading | `as`, `size={1..5}` | Семантический тег независимо от визуального размера |
| Icon | `name`, `size`, `strokeWidth` | Единая точка импорта Lucide, имена в kebab-case |
| Modal | `title`, `onClose`, `variant="modal|drawer"` | Общая оболочка окон, используемая через registry/store |

`Button as={Link} href="/dota/"` сохраняет размеры кнопки и locale-aware переход. `Button as="span"` может показывать CTA внутри целиком кликабельной карточки без вложенного button. `Panel as="button" interactive` применяется к содержательным карточкам выбора, а `Panel as={Link} interactive` — к карточкам навигации.

## Цвета

Палитры находятся в `src/app/[locale]/layout.scss`. Имена описывают роль, а не конкретный оттенок:

| Семейство | Назначение |
|---|---|
| `--color-page` | Фон страницы |
| `--color-material`, `-raised`, `-hover`, `-input` | Поверхности и состояния |
| `--color-border`, `--color-border-muted` | Контур контрола и разделители |
| `--color-text`, `--color-text-muted` | Основной и второстепенный текст |
| `--color-accent`, `-hover`, `-soft` | Основное действие и его состояния |
| `--color-text-on-accent` | Текст на акцентной кнопке |
| `--color-danger`, `-hover`, `-soft`, `--color-text-on-danger` | Опасные действия и ошибки |
| `--color-success`, `-soft` | Успешные состояния |
| `--color-focus` | Фокус клавиатуры |
| `--color-backdrop` | Подложка модалки |
| `--color-image-overlay` | Тёмная подложка поверх изображения, независимо от темы |
| `--color-game-accent`, `--color-game-danger`, `--color-game-border` | Только собственная тема игры |

Алиасы `surface`, `primary`, `link`, `gold`, `line` для цветов сайта удалены: для одной роли используется одно имя. `--color-white` и `--color-black` — фиксированные цвета ассетов, а не замена семантическому тексту/фону. Декоративные брендовые цвета карточек будущих игр остаются локальными; читаемый текст использует цвета сайта.

В модалках и общих компонентах нет отдельных hex-палитр. Контраст ключевых пар (текст/поверхность, muted/hover, текст на кнопке и status/soft) проверяется тестом не ниже 4.5. Это проверка перечисленных пар, не сертификация всех возможных сочетаний.

## Геометрия и стили

- `--control-height: 44px`, `--control-padding: 12px`, `--control-gap: 8px`.
- Радиусы: `--radius-control: 8px`, `--radius-panel: 12px`, `--radius-full` для капсул.
- `--panel-padding: 20px`; отступы содержимого карточек и Panel совпадают.
- `--shadow-panel`, `--shadow-dialog` задаются отдельно для каждой темы.
- Все фиксированные CSS-значения пишутся через `rem(px)`, размеры пар width/height — через `@include size()`.
- Миксины отвечают за flex, hover, transition и брейкпоинты; компоненты-потребители содержат преимущественно layout.
- Пользовательские хуки — `src/hooks`; не копируйте состояния и вычисления компонентов в страницы.

## Темы и сохранение

В настройках доступны тёмная, светлая и системная темы. По умолчанию остаётся тёмная. Выбор хранится отдельно в `spin-arcade-appearance-v1`; сброс игрового прогресса не меняет оформление. Изменение темы применяется сразу, без перезагрузки, смена языка сохраняет выбор.

`src/lib/theme.js` содержит допустимые значения, нормализацию, вычисление системной темы и короткий head bootstrap. Bootstrap задаёт `data-theme` до показа страницы. `modules/ThemeSync` восстанавливает Zustand, слушает изменение системного предпочтения и обновляет корень документа.

Каждая Modal получает собственный `data-theme`, поэтому при размещении в fullscreen-портале внутри тёмной Dota она использует выбранную тему сайта. Не копируйте палитры в отдельные модалки. Будущие игры могут иметь свои игровые акценты, сохраняя общую оболочку сайта.

## Проверка

```bash
npm test
npm run lint
npm run build
```

Если Turbopack не может открыть служебный порт в ограниченном окружении, доступна стандартная сборка Next.js через `npm run build -- --webpack`. Это та же production-сборка приложения с другим компилятором.

В витрине проверяйте hover/focus/disabled/selected, ввод и ошибку поля, клавиатуру Select, Escape в dropdown и модалке, смену тем и перезагрузку. Размеры контролов сравниваются на реальных элементах; отдельно проверяются каталог, профиль, avatar picker и модалки игры при светлой теме.
